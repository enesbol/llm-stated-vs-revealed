# results/live/ — raw run outputs, published deliberately

Every subdirectory is one real, timestamped invocation of
`stated_vs_revealed.run` for the named environment. Never overwritten — a
new run always gets a fresh `<env>/<UTC-timestamp>/` directory.

Committed, not gitignored — unlike vendored material, these completions are
**not reproducible byte-for-byte** (temperature=1.0, no fixed inference
seed by design), so if this data isn't published here, this run's raw
evidence exists nowhere else. Includes failed/blocked/aborted runs — a run
that spent $0 and excluded everything is still real evidence, not deleted.

## Fields (manifest.jsonl)

Each line: `arm`, `replicate_index`, full `request_messages` (the exact
prompt sent), `response_content`, `response_reasoning` (the model's hidden
chain-of-thought, when returned — read this before concluding a response is
"uninformative"), `response_provider` (served provider, asserted against
the pin), `usage_*` (tokens and the OpenRouter-computed real cost — never a
local estimate), `error`, `excluded`, `exclusion_reason`, `duration_seconds`,
`timestamp_utc`.

## Label files

Separate files per run, never merged in place: `mechanical_labels.jsonl`,
`human_labels.jsonl`, `judge_labels.jsonl`, `consultative_labels.jsonl`
(model-rater readings, with a `raters` field naming each rater's own label
and a `resolution` field explaining how disagreements were settled), each
row keyed on `{"arm": ..., "replicate_index": ..., "label": ...}`.
`labels_merged.jsonl` is GENERATED by `analyze.py` (human > mechanical >
judge priority) as a local audit artifact, gitignored, regenerate it
yourself rather than expecting it in a fresh clone.

`summary.md` / `summary.json` (one level up, in `results/`) are generated by
`python -m stated_vs_revealed.reproduce` from every run directory here —
never hand-edited.
